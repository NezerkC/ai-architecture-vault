# SKILL: START NEW PROJECT

1. Activa el rol de **Agente Product Manager** para realizar las preguntas de descubrimiento del negocio.
2. Genera el documento `docs/PRD.md`.
3. Pasa el testigo al **Agente Scrum Master** para desglosar el PRD en épicas e historias con criterios de aceptación.
4. Genera `docs/BACKLOG.md` y carga las tareas refinadas en el Tablero Kanban.
5. Entrega la primera historia técnica al **Agente Orquestador (Lead Architect)**.
